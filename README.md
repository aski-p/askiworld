# ASKIWORLD

제공된 콘셉트 아트를 실제 조작 가능한 홈페이지로 재구성한 카툰 마을형 페이지 포털입니다.

## 조작
- `WASD` 또는 방향키로 캐릭터 이동
- 모바일 방향 버튼 지원
- 길을 클릭하면 해당 위치로 자동 이동
- Agent Office 건물이나 왼쪽 카드를 클릭하면 문 앞으로 자동 이동
- 문 앞에서 `E` 또는 `Enter`를 누르면 문이 열리고 Agent Office로 이동

## 현재 연결
- Agent Office: `https://agent-office.askipgh.chatgpt.site/`
- Studio / Library / Windmill: 준비 중

## 실행
```bash
npm start
npm run check
```
`/healthz`에서 배포 상태를 확인할 수 있습니다.
